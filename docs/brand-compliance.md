# Brand Guide compliance audit

Implementation: `@bacon/design-system` v1.0.0
Source of truth: _Bacon Brand & Interface Guide_, version 1.0 (sections 00–14)

Every row below was checked against the guide text, against the implementation, and — where a test
can express the rule — against a test that fails if the rule is broken. A row is **PASS** only when
the rule is enforced or verified, not when the output merely resembles the guide. Rows that are
implemented but not verified in this environment, or that the guide states as copy/practice rather
than something code can hold, are marked **PARTIAL** with the gap named.

**Summary: 71 rules audited — 61 PASS, 10 PARTIAL, 0 FAIL.**

## Known gaps

These are the ten PARTIAL rows, restated plainly.

1. **The focus ring is a token, not a rendered state.** React Native on phones has no keyboard
   focus model. `focusRing()` is implemented and tested; wiring it to `onFocus`/`onBlur` for
   React Native Web and TV is outstanding.
2. **The font fallback stack cannot behave as a stack on device.** React Native resolves one
   `fontFamily`. If Quicksand is not registered, the platform font is used — not Nunito.
3. **"Two buttons per row maximum" is not counted.** Even splitting is supported via `fill`.
4. **Copy rules are documented, not enforced** — first-person destructive wording, question-shaped
   labels, sentence case. A library cannot read intent from a string.
5. **The period switcher is chips, not an underlined control.** The guide's own screens show chips;
   the underline note appears only in the typography section.
6. **Storybook is authored but not rendered here.** The 30 stories typecheck and lint, and the
   components they use are covered by 239 tests — but no emulator or device ran them in this
   environment, so the catalogue has not been visually reviewed.
7. **The example app has not been launched.** Its source is complete and it imports only through
   the public API, but its dependencies were not installed and Metro was not run here. CI includes
   a job that installs it and typechecks it against the built package.
8. **Quicksand is not bundled**, by design — font files in a library duplicate in every consumer.
   Rendering therefore depends on the app registering the four weights.
9. **`assertSpacing` / `assertRadius` / `assertUiColor` / `assertMutedUsage` are opt-in.** They are
   dev-time guards for consuming apps, where this repository's lint does not run; the library does
   not call them on itself because the lint rules already cover it.
10. **List memoisation is left to the consumer.** Styles are memoised and `StyleSheet.create` is
    used throughout, but `WalletTile` and `TransactionRow` are not wrapped in `React.memo`, because
    memoisation only pays off when the caller's props are stable — which is the app's decision.
